# NOVA 360 usage guide

1. Open `/fr` or `/en`. Select language once in the global header. Use Current for the current operational view; Baseline remains the verified original snapshot.
2. Read the dashboard, then detailed state at `/project/overview`. Status is based on actual independent launch conditions, not an invented health percentage.
3. Open `/questions`. Ten numbered cards contain answers, nuance, confidence/uncertainty and evidence. Stable IDs/anchors are still Q01–Q10; official answers are protected.
4. Click a citation to inspect the original with its exact line/page/cell/image locator. Close the dialog before using the global language control. Originals retain their original language.
5. `/documents` is the file library; `/evidence` is the detailed source explorer. Both use the same preserved originals but have distinct screens.
6. The large header question field opens Ask NOVA (`/ask`) for verified project answers. Ctrl/Cmd K or the search icon opens interactive search (`/search`) with type/state filters and keyboard results.
7. `/project/timeline`, `/project/decisions`, `/project/contradictions` and `/actions` explain history, decisions, contradictions and documented versus recommended next steps. Historical records are not rewritten by an event.
8. `/impact` accepts a declared event, source/locator, author/authority and occurred date. Analyze first; confirm only evidence-supported candidates; compare changed/new/unchanged/pending facts and actions; explicitly save. Baseline is never overwritten. Export/import the journal to move accepted events between separate databases.
9. `/brief` prints an A4 takeover brief or exports text. Included FR/EN PDFs represent the sealed baseline, not private or synthetic events from a developer DB.
10. Login/register are optional for ordinary judge tools. Public registration creates USER. ADMIN-only Question Bank and Users require the admin created by your own local setup. Roles are read-only; account activation and custom question controls have safeguards.
11. Bottom-right NOVA Support helps with UI/navigation. Common intents answer locally instantly. Open-ended help may use optional Gemini; it waits at most about 10 seconds before local fallback. Click outside, press Escape or use X to close. This assistant never changes project or account data.

All route examples after step 1 are prefixed with `/fr` or `/en`. Source originals and precise locators remain the authority; missing information is reported explicitly. See the root README for installation and the technical docs for limitations.
