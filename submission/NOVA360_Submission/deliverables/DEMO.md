# Five-minute judge demo

Prepare your locally chosen ADMIN credentials and a fresh/rehearsal database; use the real judge-provided event during evaluation. Do not save a synthetic event into the canonical demo DB. Keep the two PDF briefs ready. All routes below use the final sidebar/top bar; no per-module FR/EN switch exists.

| Time | Action | One point to communicate |
|---|---|---|
| 0:00–0:25 | Open `/fr` | “NOVA 360 transforme les informations dispersées en une mémoire projet traçable et actionnable.” Six concise cards, one project question field. |
| 0:25–0:50 | Open `/fr/project/overview` | Approved date is conditional; the three launch conditions are independent. Current is the presentation default; Baseline is protected history. |
| 0:50–1:30 | Open `/fr/questions#Q06`; click INV-003 evidence | Show answer, nuance and exact original/locator. An unapproved invoice line is not an approved spend; a recommendation is not an issued credit. Close the evidence dialog. |
| 1:30–1:55 | Open `/fr/project/timeline`, then `/fr/project/contradictions` | Proposal, approval and fact dates explain apparently conflicting sources. A newer filename alone does not make a fact current. |
| 1:55–2:25 | Ctrl/Cmd K, search INV-003, filter Questions; close palette and use global EN | Same identity and evidence in both languages. The main header question field is Ask NOVA. |
| 2:25–2:50 | Log in using your chosen ADMIN; open `/en/admin`, then `/en/admin/users` | Custom bilingual questions and activation controls are server-protected; official answers stay protected. Do not spend time editing during the demo. |
| 2:50–4:30 | Open `/fr/impact`; paste the actual new event, source/locator, authority and occurred date | Analyze, inspect candidate values/states, confirm only what the event establishes, show before/after and affected actions, then explicitly save. Show Current versus Baseline and raw event evidence. A proposal does not replace approval; delivery does not validate; one condition does not close the others. |
| 4:30–5:00 | Open `/fr/brief`; mention bottom-right Support | Printable takeover brief and next actions. Support answers common UI help locally; optional Gemini has a 10-second fallback budget. Ask NOVA is the factual experience. |

If no event is provided, demonstrate the analysis preview only, with text clearly labelled “Simulation — non corpus”, without saving it. Rehearse in an isolated DB. If AI is unavailable, demonstrate the fast local risk/evidence prompt; every judged project tool works without an API key.
