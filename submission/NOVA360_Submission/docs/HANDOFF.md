# NOVA 360 final package handoff

Run commands from `app/`: Node.js 24, npm ci, copy .env.example to .env, choose private ADMIN_EMAIL/ADMIN_PASSWORD (10+ characters) and SESSION_SECRET (32+ random characters), then npm run db:setup and npm run dev. Leave the Gemini key blank for an offline/local-support demo. Default URLs are http://127.0.0.1:3000/fr and /en. Production: stop dev, npm run build, npm run start. Exact measured setup/route checks are in FINAL_QA.md.

SQLite is created in app/data/runtime/nova.db. Only reviewed generated fixtures and original source files are shipped; existing users/sessions/custom questions/events and DB backups are excluded. Migrations are additive; seed creates a missing env-admin and preserves existing users/admin passwords/project records on rerun. Changing ADMIN_PASSWORD does not reset an existing account. Avoid db:reset on a working DB. Fresh validation was isolated from the developer's working database.

Normal project pages remain public for judges. Local registration creates USER and signs in; ADMIN is created only by setup. Server-side route/API guards protect Question Bank and Users in both locales. ADMIN may manage custom bilingual questions and user activation; roles are read-only, official questions protected, self/last-admin safeguards retained. Cookies are opaque, httpOnly, SameSite=Lax, seven-day, Secure in production; logout revokes the DB session. See AUTH.md and ADMIN.md.

Global FR/EN switch, sidebar and one header natural-language field lead to factual Ask NOVA. Ctrl/Cmd K/search icon opens search. Documents (/documents) is distinct from Traceable Evidence (/evidence). Question badges are 1–10 with stable Q01–Q10 anchors. Baseline is sealed; Current overlays accepted events; Impact explicitly analyzes/confirms/saves changes. Original evidence retains exact locators and original language.

Support is read-only UI help, separate from Ask NOVA. NAVIGATION/ADMIN_HELP/AUTH_HELP/SEARCH_HELP/IMPACT_HELP and known feature explanations answer locally instantly; project-fact requests redirect to Ask NOVA. GENERAL_SUPPORT/UNKNOWN/open-ended feature help may use server-only @google/genai with the configured Flash-Lite model, strict schema and safe link/output guards. SDK/app deadline is 10 seconds; browser transport deadline is 15 seconds. Failure or absent/disabled key falls back locally. The local-mode label is also normal for intentional deterministic answers. No paid API was used in final automated tests.

Optional Gemini variables belong only in your local .env; restart after changes. ai:smoke/ai:stages are explicit quota-consuming diagnostics, not startup or automated tests. No key is bundled; provider reliability is not guaranteed. Existing mascot is public/nova-support-mascot.png with a fallback; the panel closes via outside click, Escape or X. Chat history is bounded in memory; no streaming or stored conversations.

Schema/data/baseline/official answers/evidence/auth behavior is unchanged by packaging. Source dependencies, migrations, seed helpers and tests are included; installation/build/test artifacts and the legacy standalone Python demonstration/development scripts are excluded. db:verify needs app/docs/QUESTION_ANSWERS.md, which is retained verbatim. data:validate uses standard Python and checks original/baseline hashes.

Production follow-ups: HTTPS, persistent disk/backups, trusted proxy/shared limiter, authentication recovery/verification/session cleanup and broader support grounding evaluations. Role editing and multiple projects are not implemented. See README_SUBMISSION.md, usage/demo documents and known uncertainties. No commit, push, deployment or Devpost upload was performed.
