# Evidence method

Use corpus content only for NOVA facts. Formal approvals outrank proposals; validation outranks delivery announcements for acceptance. Newer filenames and modification times have no authority.

Maintain historical claims and explain supersession. A resolved root cause does not automatically undo its approved schedule decision. Each go-live condition changes independently.

SHA-256 matches detect exact duplicate files and MIME attachment copies; these count as one evidence lineage. Non-identical content duplicates require manual examination.

Use PDF pages, XLSX cells, text/email lines, dated ticket comments and manually inspected screenshot regions. Never claim machine-derived image precision.

Confidence is strong/moderate/uncertain with an explanation, never a percentage. Missing owners, deadlines, payments and validations remain explicitly unconfirmed.

Manual work performed: read all extracted text/PDF pages/spreadsheet cells; inspected all eight ticket captures and the challenge illustration. Curated 40 citations and ten answers in `scripts/curate.py`. Source IDs persist by path across reruns. Worksheet activity dates are not document-authoring dates; metadata without an explicit author stays unknown.

Baseline creation is write-once: curate refuses to overwrite differing baseline bytes; validation checks baseline SHA-256 and all original source hashes. Generated question/fact edits require explicit reconciliation rather than silently updating the sealed snapshot.

Judge events: raw text is saved as its own evidence along with user-entered source/locator, author/authority, occurred time, received time and confirmed candidate excerpts. New facts receive moderate evidence quality because user confirmation is not independent verification. Proposal and delivery events remain in the journal even when no canonical fact changes.

## Iteration 2 preservation

Database migration is verified by exact payload and relation equivalence before switching runtime reads. Protected triggers and API rules prevent admin edits to original evidence, official Q01–Q10 and baseline. English is a derived presentation with identical underlying IDs/relations; original quotations, filenames and locators remain faithful and labelled. A custom answer is team-curated, with moderate/uncertain confidence rather than inheriting official verification. Citation selection alone does not establish independent corroboration. Shared database events retain declared provenance and human-confirmed classification; the engine's authority/temporal rules are unchanged.
